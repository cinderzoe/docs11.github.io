BasicForm 组件 ​

对 Element 的 Form 表单的二次封装

示例 ​

vue
<template>
  <BasicForm
    ref="BasicFormRef"
    v-loading="loading"
    v-bind="{ model: formData, schemas, labelWidth: '200px', span: 2 }"
  />
</template>
<script>
import BasicForm from '@/components/BasicForm';
export default {
  data() {
    return {
      formData: {},
    };
  },
  computed: {
    schemas() {
      return [
        {
          field: 'id',
          label: '输入框',
          component: 'Input',
        },
      ];
    },
  },
};
</script>

Mehtods ​

通过 ref 可获取到 BasicForm 组件内部的函数

submit
类型：(validate?: boolean) => Promise<SubmitResponseParams>;
说明：提交表单

setFieldsValue
类型：(fields: Recordable) => void;
说明：设置表单字段值

getFieldsValue
类型：() => Recordable;
说明：获取表单字段值

resetFields
类型: () => void;
说明：重置表单

clearValidate
类型：() => void;
说明：清空校验

validateField
类型：(props: array | string) => Promise<boolean>;
说明：校验表单的指定项

validate
类型：() => Promise<boolean>;
说明：校验整个表单

SubmitResponseParams
ts
export interface SubmitResponseParams {
  valid: boolean;
  form?: Recordable;
}

Props ​

参数名类型默认值说明
modelObject() => ({})模型对象
schemasArray<FormSchema>-表单配置项
spanNumber1栅格跨度

FormSchema 表单项 ​

表单每一项的配置参数

参数名类型默认值说明
fieldString-字段名称 (必填)
labelString-表单项显示名称
componentComponentType-组件类型
componentPropsRecordable / ((args: ComponentPropsCallbackParams) => Recordable)-组件属性配置
defaultValueany-表单项默认值
valueHandle(props:ValueHandleParams) => void-值处理函数
rulesArray<Recordable> / ((renderCallbackParams: RenderCallbackParams) => Array<Recordable>)-校验规则 ,具体查看 element 表单里面的规则配置
requiredBooleanfalse是否必填
ifShowBoolean / (renderCallbackParams: RenderCallbackParams) => Booleantrue是否显示该表单项
spanNumber-栅格布局的跨度, 1占满一栏
onChange(params:ValueHandleParams) => void-值变化回调函数
ValueHandleParams

valueHandle，onChange 函数的参数类型

ts
interface ValueHandleParams {
  value: any;
  action: ActionType;
  formModel: Recordable;
}
ComponentPropsCallbackParams

componentProps 函数的参数类型

ts
interface ComponentPropsCallbackParams {
  value: any;
  formModel: Recordable;
}
RenderCallbackParams

rules，ifShow 为函数时的函数参数类型

ts
export interface RenderCallbackParams {
  formModel: Recordable;
}

ComponentType 组件类型 ​

ComponentType 是 schema 里面的可选组件类型，以下是所有可用的组件类型，若要增加更多Element的表单组件，需要在 BasicForm 里面引入Element的组件并注册

ts
type ComponentType =
  | 'SSwitch'
  | 'DatePicker'
  | 'Select'
  | 'Cascader'
  | 'Input'
  | 'InputNumber'
  | 'Radio'
  | 'Checkbox'
  | 'UploadFile'
  | 'ApiTree'
  | 'Divider'
  | 'TableInput'
  | 'Picture';

Rules 表单校验 ​

表单校验需要通过 schema 内的 rules 属性进行配置。 自定义校验规则, 具体规则配置参考官网

ts
//必填
{
  rules: [{ required: true, message: '请选择会议负责人' }],
}

//必填被其他属性控制
{
  rules: ({ formModel }) =>
    [{ required: formModel.isRegistration, message: '请选择报名开始日期' }],
}

//复杂校验
{
  rules: ({ formModel: { stratRegistrationDate, isRegistration } }) => [
            { required: isRegistration, message: '请选择报名截止日期' },
            {
              validator: (_rule, value, callback) => {
                if (stratRegistrationDate && new Date(value) < new Date(stratRegistrationDate)) callback(new Error('报名截止日期不能小于开始日期'));
                else callback();
              },
            },
          ],
}

Select 选择器 ​

基于Element 的 Select 组件二次封装，支持 options 列表数据 和 远程接口数据的下拉选择器

Props ​
参数名类型默认值说明
optionsArray<Object>-选项数组, Object 的属性为 labelField,valueField的属性值
valueString / Number-当前选中值
apiFunction-远程数据接口
resultFieldString-接口返回数据字段名
paramsObject-接口请求参数
labelFieldString'label'下拉框选项标签字段名
valueFieldString / Number / Object'value'下拉框选项值字段名
valueKeyString'value'值键名
optionPropsObject() => ({ label: 'label', value: 'value' })选项属性配置
readonlyBoolean-是否只读
optionDisabledFunction-选项禁用判断函数

Cascader 级联选择器 ​

基于 Element 的 联级选择器的二次封装，支持原始的可选项数据源配置，也支持远程数据源配置

更多参数，参看官方示例

Props ​
参数名类型默认值说明
valueObject-当前选中值
optionsArray-选项数组
apiFunction-远程数据接口
resultFieldString-接口返回数据字段名
paramsObject-接口请求参数
labelFieldString'label'下拉框选项标签字段名
valueFieldString | Number | Object'value'下拉框选项值字段名
valueKeyString-值键名, 当 valueField 是 Object 时，需要配置 valueKey
