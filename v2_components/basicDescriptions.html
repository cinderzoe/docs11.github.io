basicDescriptions 组件 ​

列表形式展示多个字段

示例 ​

vue
<template>
  <BasicDescriptions v-bind="{ schemas: schemas, value: meeting, border: true, column: 2 }" />
</template>
<script>
import BasicDescriptions from '@/components/BasicDescriptions';
export default {
  components: { BasicDescriptions },
  data() {
    return {
      schemas: [{ label: '会议名称', field: 'meetingName' }],
    };
  },
};
</script>

Props ​

更多参数参考官方示例

参数名类型默认值说明
labelString-表单项标签文本
fieldString-表单字段名（必填）
componentComponentType-使用的组件名称（如：Input/Select/DatePicker 等）
componentPropsObject-组件属性配置对象或返回配置对象的函数
spanNumber1栅格布局的列跨度（默认占 1 列）
renderT(value) => T-自定义渲染函数
ifShowBoolean/(value) => Booleantrue控制是否显示该表单项（支持布尔值或返回布尔值的函数）
