Search 组件 ​

对 Form 组件的二次封装，多用于 List 组件上面的搜索选项 ， Search 组件和 List 组件搭配，组合成一个有搜索选项的列表

示例 ​

vue
<template>
  <c-search @register="register" @change="searchChange"></c-search>
</template>

<script setup lang="ts">
import { useSearch } from '@/hooks/search';
const [registerSearch, { reset }] = useSearch({
  schemas: [
    {
      field: 'custName',
      component: 'Search',
      componentProps: {
        placeholder: '请输入商业名称',
      },
    },
    {
      field: 'region',
      label: '省市',
      component: 'AreaPicker',
      valueHandle: (val) => val && val.join(','),
      span: 1,
    },
    {
      field: 'businessClass',
      label: '商业等级',
      component: 'Picker',
      componentProps: {
        api: businessLevelApi,
        labelField: 'dictLabel',
        valueField: 'dictValue',
      },
      span: 1,
    },
  ],
});
</script>

useSearch ​

Search 组件提供了 useSearch ，用于调用函数内部的方法

参数介绍 ​

ts
const [register, methods] = useSearch();

register ​

register 用于注册 useSearch , 如果需要使用 useSearch 的提供的 api, 需要把 register 传入组件 Search 的 onRegister 里面

methods ​

reset
类型：() => Promise<void>
说明：重置搜索表单

getFieldsValue
类型：(field?: string) => Recordable | any;
说明：获取搜索表单属性值

setFieldsValue
类型：(arg: Recordable) => void;
说明：设置搜索表单属性值

Props ​

参数名类型默认值说明
fieldstring-字段名称 (必填)
labelstring-字段标签文本
componentComponentType-使用的组件类型
defaultValueany-默认值
componentPropsRecordable / ((arg: ComponentPropsRenderParams) => Recordable)-组件属性配置
valueHandle(value: any, model: Recordable) => any-值处理函数
onChange(arg: { value: any; action: ActionType }) => any-值变化回调函数
spannumber-栅格占据的列数
ifShowboolean / ((model:Recordable) => boolean)-是否显示该字段

ComponentPropsRenderParams

ts
export interface ComponentPropsRenderParams {
  model: Recordable;
  actionType: ActionType;
}

ActionType 同 useSearch 调用的返回函数一样，前往

ts
type ComponentType = 'ApiSelect' | 'Calendar' | 'DateRange' | 'Picker' | 'Search' | 'Sort' | 'AreaPicker' | 'ApiTree';

日历组件，选择任意范围内的日期

对 uni-ui 的 uni-calendar 组件的封装 ，更多参数查看官方文档

Props ​
参数名类型默认值说明
valueArray<String>[]当前选中的值数组
placeholderString / Array<String>-占位文本（单/多选模式）

Picker 选择器 ​

对 uView 的 Picker 组件的封装，更多参数查看官方文档

Props ​
参数名类型默认值说明
valueString / Number-当前值
optionsArray<FormOptionsType>[]选项列表
placeholderString-占位文本
api(arg?: Recordable) => Promise<ApiReturnType>null获取数据的异步函数
paramsRecordable{}请求参数
resultFieldString''接口返回的数据字段名
labelFieldString'label'显示文本的字段名
valueFieldString'value'值字段名
