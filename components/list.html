List 组件 ​

对 uni-app 的内置组件 scroll-view 进行封装，下拉加载更多数据的列表

示例 ​

vue
<template>
  <c-list @register="register">
    <template v-slot="{ data: { id, custName, storeType, storeLevel, provinceName, cityName } }">
      <view @click="toDetailPage(id)" class="bg-white border-radius mg-b-8 pd-8 mg-x-5 shadow">
        <view>{{ id }}, {{ custName }}, {{ storeType }}, {{ storeLevel }}, {{ provinceName }}, {{ cityName }}</view>
      </view>
    </template>
  </c-list>
</template>

<script setup lang="ts">
import { useList } from '@/hooks/list';

const [register, { reload, getDataSource, updateDataRecord }] = useList({
  api: storePageApi,
  params: { custType: 3 },
  pageSize: 20,
  resultField: 'records',
  resultParams: ['id', 'custName', 'storeLevel', 'storeType', 'provinceName', 'cityName'],
  rowKey: 'id',
});

function toDetailPage(id) {
  uni.navigateTo({ url: '/pages/store/detail?id=' + id });
  uni.$once('refreshList', (record) => updateDataRecord(id, record));
}
</script>

useList ​

List 组件提供了 useList , 用于调用函数内部的方法

参数介绍 ​

ts
const [register, methods] = useList(props);

register ​

register 用于注册 useList , 如果需要使用 useList 的提供的 api, 需要把 register 传入组件 List 的 onRegister 里面

vue
<template>
  <c-list @register="register" />
</template>
<script lang="ts" setup>
import { useList } from '@/hooks/list';
const [register, methods] = useList();
</script>

methods ​

reload
类型：(params?: Recordable) => Promise<void>;
说明：刷新列表

getDataSource
类型：() => Recordable
说明：获取列表数据

updateDataRecord
类型：(rowKey: string | number, record: Recordable) => void;
说明：不刷新列表更新指定行的数据

deleteDataRecord
类型: (rowKey: string | number | string[] | number[]) => void;
说明：不刷新列表删除指定行的数据

Props ​

参数名类型默认值说明
api(arg?: Recordable) => Promise<ApiReturnType>-获取数据的异步 API 函数
immediateboolean-是否立即执行 API 请求
paramsRecordable-API 请求参数
afterFetch(result: any) => void-数据获取后的回调函数
resultFieldstring-API 返回结果中需要提取的数据字段名
pageSizenumber20分页大小
resultParamsstring[]-需要从结果中提取的参数列表
subtractHeightnumber-需要减去的高度值（通常用于布局计算）
rowKeystring-行数据的唯一标识字段名
